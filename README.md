# 时光守护siri123 (TimeGuardian Siri 123)

基于 `主修实时翻译.txt` (v6.0 Zero-Latency Pro) 构建的全新 iOS 越狱综合插件项目。

## 🌟 核心特性
1. **主修实时翻译 (v6.0 Zero-Latency Pro)**：
   - **零音质损伤内录听译**：彻底废除 PlayAndRecord 麦克风抢占，手机媒体音量与音质 100% 原生保持不变。
   - **字幕自动滚动刷新**：增量断句 + 自动上推滚动字幕流，字幕满了自动换行刷新，绝不卡死。
   - **毫秒级极速翻译**：关闭模型思考延迟 (thinkingBudget=0)，移除单请求阻塞锁，随听随出。
   - **框选与听译自由缩放**：右下角拖拽手柄自由缩放取景窗与字幕条。
   - **原位覆膜翻译**：基于 Apple Vision 框架检测文字坐标，原位毛玻璃覆膜贴纸精准替换。

2. **多模式智能助理**：
   - 🎙️ **Live 实时全双工语音**（Gemini Live Bidi / OpenAI Realtime）
   - 📹 **独立视频 AI**（7阶段相机状态机 + 实景视觉问答）
   - 💬 **纯文本打字交流**
   - 🌐 **实时字幕与屏幕翻译**

3. **系统级自动化 Agent**：
   - 微信自动发送消息、读未读消息、快捷收付款与扫一扫
   - 系统级硬件控制（音量、亮度、手电筒、Wi-Fi/蓝牙、低电量等）
